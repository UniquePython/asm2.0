# asm2.0

The future of asm.

## Quick Start

Clone the repository:
```bash
# Using HTTPS
git clone https://github.com/UniquePython/asm2.0.git

# Using SSH
git clone git@github.com:UniquePython/asm2.0.git

cd asm2.0
```

Build the project:
```bash
make clean
make build
```

Run:
```bash
make run ARGS="examples/prog.asm2"
```
